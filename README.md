# Verilog

## Overview

This repository contains my Verilog HDL practice, design implementations, and coding exercises developed while learning digital design and RTL development.

The repository serves as a collection of Verilog implementations covering fundamental digital logic concepts, combinational circuits, sequential circuits, and commonly used digital design structures.

## Topics Covered

- Verilog fundamentals and syntax
- Combinational logic design
- Sequential logic design
- Arithmetic and logic circuits
- Multiplexers and demultiplexers
- Encoders and decoders
- Counters
- Shift registers
- Finite State Machines (FSMs)
- Digital design exercises and problem-solving

## Repository Organization

The source files are organized by topic and design functionality to make the code easier to navigate, understand, and reuse.

Each example is intended to demonstrate a specific Verilog concept or hardware design.

## HDL

- Verilog

## Tools

The code is written for HDL simulation and verification environments that support Verilog.

## Purpose

The purpose of this repository is to strengthen my understanding of RTL design, digital logic, hardware description languages, and fundamental hardware implementation concepts through hands-on coding and practice.
